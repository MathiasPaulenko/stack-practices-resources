# Checklist de Mejores Prácticas de Seguridad

Checklist imprimible de seguridad de aplicaciones extraída de la
[Guía de Mejores Prácticas de Seguridad](https://stackpractices.com/es/guides/security-best-practices-guide/)
de StackPractices.

## Archivos

- `security-checklist.md` — formato checkbox para docs, wikis y plantillas de PR
- `security-checklist.csv` — formato hoja de cálculo para auditorías (columnas Status y Notes)

## Uso

Copia la versión Markdown en el `SECURITY.md` de tu repo o en la plantilla de
PR, o importa el CSV en una hoja de cálculo y usa las columnas Status/Notes en
tu revisión de seguridad trimestral.
