# Security Best Practices Checklist

Printable application-security checklist extracted from the
[Security Best Practices Guide](https://stackpractices.com/guides/security-best-practices-guide/)
on StackPractices.

## Files

- `security-checklist.md` — checkbox format for docs, wikis, and PR templates
- `security-checklist.csv` — spreadsheet format for audits (Status + Notes columns)

## Usage

Drop the Markdown version into your repo's `SECURITY.md` or PR template, or
import the CSV into a spreadsheet and use the Status/Notes columns during a
quarterly security review.
