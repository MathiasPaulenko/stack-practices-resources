# Threat Modeling — Session Worksheet & Worked Example

Companion files for the [Threat Modeling guide](https://stackpractices.com/guides/threat-modeling-guide/):

- `session-worksheet.md` — printable worksheet for a 90–120 minute session: DFD checklist, STRIDE threat table, risk scoring matrix, mitigation register with owners.
- `payment-api-worked-example.md` — the payment-API example from the guide: flow, 11 identified threats, risk scoring, and the 8-item mitigation plan.

Copy the worksheet into your repo's `docs/` folder and fill it in during the session. Keep the finished model next to the architecture docs — a model nobody can find is a model nobody updates.
