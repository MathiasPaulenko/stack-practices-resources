# Modelado de Amenazas — Hoja de trabajo y ejemplo resuelto

Archivos complementarios de la [guía de Modelado de Amenazas](https://stackpractices.com/es/guides/threat-modeling-guide/):

- `session-worksheet.md` — hoja imprimible para una sesión de 90–120 minutos: checklist DFD, tabla de amenazas STRIDE, matriz de puntuación de riesgo y registro de mitigaciones con responsables.
- `payment-api-worked-example.md` — el ejemplo de la API de pagos de la guía: flujo, 11 amenazas identificadas, puntuación de riesgo y plan de mitigación de 8 ítems.

Copia la hoja al `docs/` de tu repo y rellénala durante la sesión. Guarda el modelo terminado junto a la documentación de arquitectura — un modelo que nadie encuentra es un modelo que nadie actualiza.
