# Secure Coding Guide — Companion

Downloadable companion files for the [Secure Coding Practices guide](https://stackpractices.com/guides/secure-coding-guide/) on StackPractices.

## Contents

- `secure-code-review-checklist.md` — printable secure code review checklist (23 items, English)
- `secure-code-review-checklist.es.md` — la misma checklist en español
- `secure-code-review-checklist.csv` — the same checklist in CSV for importing into your tracker or CI reports

## Usage

Use the checklist during code review or before every release. Anything left unchecked is a finding: document it, assign an owner, or block the merge depending on severity.
