# Guía de Codificación Segura — Companion

Archivos descargables que acompañan a la [guía de Prácticas de Codificación Segura](https://stackpractices.com/es/guides/secure-coding-guide/) de StackPractices.

## Contenido

- `secure-code-review-checklist.md` — checklist imprimible de revisión de código segura (23 ítems, inglés)
- `secure-code-review-checklist.es.md` — la misma checklist en español
- `secure-code-review-checklist.csv` — la checklist en CSV para importar en tu tracker o reportes de CI

## Uso

Usa la checklist en la revisión de código o antes de cada release. Todo lo que quede sin marcar es un hallazgo: documéntalo, asígnale un responsable o bloquea el merge según la severidad.
