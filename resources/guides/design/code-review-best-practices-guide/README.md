# Code Review Best Practices — Companion Assets

Companion to the StackPractices guide [Code Review Best Practices](https://stackpractices.com/guides/code-review-best-practices-guide/).

## Files

| File | Purpose |
| --- | --- |
| `src/review-checklist.md` | Printable review checklist by category — paste into PR templates, team wikis or onboarding docs. |
| `src/comment-examples.md` | BAD/GOOD review-comment pairs for training reviewers on phrasing feedback. |

Copy either file as-is; adjust the checklist categories to what your reviews actually check.
