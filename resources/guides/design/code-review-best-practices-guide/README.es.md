# Mejores Prácticas de Code Review — Assets companion

Companion de la guía de StackPractices [Mejores Prácticas de Code Review](https://stackpractices.com/es/guides/code-review-best-practices-guide/).

## Archivos

| Archivo | Propósito |
| --- | --- |
| `src/review-checklist.md` | Checklist de revisión imprimible por categoría — pégala en plantillas de PR, wikis del equipo o docs de onboarding. |
| `src/comment-examples.md` | Pares de comentarios MAL/BIEN para entrenar a revisores en cómo formular feedback. |

Copia cualquier archivo tal cual; ajusta las categorías de la checklist a lo que vuestras revisiones comprueban de verdad.
