# Guía de Calidad de Datos — Recursos complementarios

Assets ejecutables de calidad de datos para la [Guía de Calidad de Datos](https://stackpractices.com/es/guides/complete-guide-data-quality/).

| Archivo | Qué |
|---------|-----|
| profile_dataset.py | Reporte ydata-profiling + perfil manual pandas |
| orders_suite.py | Suite GX 1.x + flujo validation definition |
| pandera_schemas.py | DataFrameSchema Pandera con validación lazy |
| orders_checks.yml | Checks Soda Core (warn/fail, freshness, anomalías) |
| anomaly_detection.py | Funciones de detección por z-score |
| pipeline_with_quality.py | DAG Airflow con puertas de calidad + PostgresHook |
