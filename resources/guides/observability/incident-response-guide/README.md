# Incident Response Process: Step-by-Step Guide

Companion resources for the guide [Incident Response Process: Step-by-Step Guide](https://stackpractices.com/guides/incident-response-guide/).

## Contents

| File | What it is |
|------|------------|
| `incident-declaration-checklist.md` | Checklist to decide when an alert becomes an incident and declare it properly |
| `status-update-template.md` | Stakeholder update template with cadence per audience |
| `incident-resolution-checklist.md` | Checklist to formally resolve and close an incident |
| `service-runbook-template.md` | Per-service runbook skeleton: triggers, first checks, mitigation ladder, escalation |
| `sev1-timeline-example.md` | A worked Sev-1 incident: roles, timeline, communications, and postmortem |

## How to use

Copy the checklists and templates into your team's wiki or incident tooling. Adapt severities, channels, and escalation paths to your organization, then test them in a game day before the next real incident.
