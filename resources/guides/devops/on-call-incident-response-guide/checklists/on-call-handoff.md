# On-Call Handoff Checklist

Cover at the end of every shift — write it down in the shared channel or handoff doc.

- [ ] **Open incidents** — status, what's been tried, who's involved
- [ ] **Ongoing degradations** — flaky alerts, services running hot, known workarounds
- [ ] **Recent changes** — deploys, config changes, infrastructure work from the last shift
- [ ] **Anything unusual** — anomalies worth watching even if they didn't page
- [ ] **Pending follow-ups** — postmortems scheduled, action items in flight
