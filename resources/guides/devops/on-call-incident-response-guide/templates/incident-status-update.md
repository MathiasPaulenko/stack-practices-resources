# Incident Status Update Template

Post in the incident channel every 10 minutes during an active incident.

```
[SEV-X] <short incident title>
- Started: <HH:MM UTC>
- Impact: <what users experience, quantified>
- Cause: <root cause or current hypothesis>
- Mitigation: <actions taken so far>
- ETA: <next update / expected resolution>
- Commander: <@person>
```

External messages describe what users experience, not internal root causes.
