# Complete Guide to CSS Grid and Flexbox — Companion Resources

Runnable HTML/CSS examples for [Complete Guide to CSS Grid and Flexbox](https://stackpractices.com/guides/complete-guide-css-grid-and-flexbox/). Each file is self-contained — open it in a browser and resize the window.

| File | Pattern |
|------|---------|
| holy-grail.html | Holy Grail layout with grid-template-areas + mobile stack |
| card-grid-subgrid.html | Aligned product cards with subgrid |
| navbar-flexbox.html | Nav bar with Flexbox distribution and gap |
| responsive-auto-grid.html | auto-fit + minmax(min(100%,280px),1fr) — no media queries |
| container-query-card.html | Same card in sidebar vs main via @container |
