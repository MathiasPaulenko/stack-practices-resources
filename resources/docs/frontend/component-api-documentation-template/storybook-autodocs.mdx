## When to use which variant

- `primary` — the single main action on a page
- `secondary` — alternative actions alongside a primary
- `ghost` — tertiary actions, filters, overflow triggers
- `danger` — destructive actions that need confirmation context
- `link` — navigation that looks like a link but keeps button sizing

## Accessibility

Icon-only usage requires `ariaLabel`. Keyboard: Enter and Space fire
`onClick`; the component renders a native `<button>`, so focus and
screen-reader behavior come for free.
