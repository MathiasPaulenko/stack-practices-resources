# Incident Response Playbook Template

Fillable markdown playbook for handling security incidents, structured around the five NIST SP 800-61 phases: Detection, Containment, Eradication, Recovery, and Lessons Learned.

## Contents

| File | Description |
|------|-------------|
| `incident-response-playbook-template.md` | Fillable playbook template (English) |
| `incident-response-playbook-template.es.md` | Plantilla rellenable del playbook (español) |

## How to use

1. Copy the template once per incident type (data breach, ransomware, DDoS, insider threat) — a useful playbook is specific, not generic.
2. Replace the `<Incident Type>` placeholder and adapt the checklists to your tooling (SIEM, firewall, identity provider).
3. Keep it under version control next to your runbooks and link it from your on-call documentation.
4. Run a tabletop exercise quarterly and update the playbook with what you learn.

The checklist doubles as the incident timeline: the scribe ticks items during the response, which becomes the record for the postmortem.
