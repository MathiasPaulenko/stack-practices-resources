# Access Control Policy Template

Companion files for the doc [Access Control Policy Template](https://stackpractices.com/docs/access-control-policy-template/).

## Contents

| File | What it is |
|------|------------|
| `access-control-policy-template.md` | The complete policy skeleton in English — authentication, RBAC/ABAC matrices, PAM, session management, provisioning SLAs, access reviews, API key management |
| `access-control-policy-template.es.md` | The same template in Spanish |
| `exceptions-register-template.md` | Standalone exceptions register — every policy deviation gets a row with owner, expiry and status |

## How to use

Copy the template into your wiki or docs repo, fill in the `<Organization Name>` placeholder and the values that differ in your context, then follow the rollout guidance on the doc page (ratify before publishing, measure the gap first, announce with an enforcement date). Keep the exceptions register next to the policy and review it quarterly.
