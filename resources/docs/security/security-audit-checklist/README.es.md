# Checklist de Auditoría de Seguridad

Checklist descargable para auditorías de seguridad internas, que cubre siete dominios: seguridad de red, seguridad de aplicaciones, protección de datos, infraestructura, monitorización, respuesta a incidentes y cumplimiento (SOC 2 / GDPR / ISO 27001).

## Archivos

- `security-audit-checklist.md` — el checklist en Markdown, listo para pegar en una wiki o documento de auditoría
- `security-audit-checklist.es.md` — versión en español
- `security-audit-checklist.csv` — las mismas verificaciones en CSV (columnas: dominio, sección, verificación, estado, evidencia) para importar a Jira, un tracker o una hoja de cálculo

## Uso

1. Copia el archivo que encaje con tu flujo (Markdown para docs, CSV para trackers).
2. Rellena las columnas de estado y evidencia durante la auditoría.
3. Registra los hallazgos como tickets con severidad, responsable y fecha límite.
4. Repite cada trimestre y compara con la ronda anterior.
