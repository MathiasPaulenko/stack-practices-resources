# Security Audit Checklist

Downloadable checklist for internal security audits, covering seven domains: network security, application security, data protection, infrastructure, monitoring, incident response, and compliance (SOC 2 / GDPR / ISO 27001).

## Files

- `security-audit-checklist.md` — the checklist in Markdown, ready to paste into a wiki or audit document
- `security-audit-checklist.es.md` — Spanish version
- `security-audit-checklist.csv` — same checks in CSV (columns: domain, section, check, status, evidence) for import into Jira, a tracker, or a spreadsheet

## Usage

1. Copy the file that fits your workflow (Markdown for docs, CSV for trackers).
2. Fill in the status and evidence columns during the audit.
3. Track findings as tickets with severity, owner, and due date.
4. Re-run quarterly and diff against the previous round.
