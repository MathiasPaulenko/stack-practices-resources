# Plantilla de Runbook de Alertas — Archivos Complementarios

Archivos descargables de la [Plantilla de Runbook de Alertas](https://stackpractices.com/es/docs/alert-runbook-template/) en StackPractices.

- `alert-runbook-template.md` — plantilla en blanco con placeholders en cada sección (metadatos, triage, ramas de diagnóstico, mitigación, escalamiento, resolución, post-incidente).
- `runbook-high-error-rate-example.md` — ejemplo trabajado: la misma plantilla rellenada para una alerta de tasa de error en un servicio de pagos (Prometheus + Kubernetes).

Copia la plantilla en blanco junto a tus reglas de alertado, completa un runbook por alerta y enlázalo desde la anotación `runbook_url` de la alerta.
