# Documento de Diseño de Agente IA — Recursos companion

Recursos companion de la [plantilla de documento de diseño de agente IA](https://stackpractices.com/es/docs/ai-agent-design-document-template/) en StackPractices.

## Archivos

| Archivo | Descripción |
| --- | --- |
| `template.md` | Versión en blanco rellenable — 9 secciones con `[placeholders]`, lista para copiar a tu repo como `docs/agent-design.md` |
| `example-customer-support-agent.md` | Ejemplo relleno: "OrderBot", un agente de soporte de e-commerce — muestra el nivel de detalle que debe tener cada sección |

## Uso

Copiá `template.md`, completá los placeholders, borrá las secciones que no apliquen. Comparalo con el ejemplo relleno si dudás cuánto detalle alcanza — el objetivo es un documento defendible en review, no papeleo.
