# AI Agent Design Document — Companion Resources

Companion resources for the [AI Agent Design Document template](https://stackpractices.com/docs/ai-agent-design-document-template/) on StackPractices.

## Files

| File | Description |
| --- | --- |
| `template.md` | Blank fillable version — 9 sections with `[placeholders]`, ready to copy into your repo as `docs/agent-design.md` |
| `example-customer-support-agent.md` | Filled example: "OrderBot", an e-commerce support agent — shows the level of detail each section should carry |

## Usage

Copy `template.md`, fill the placeholders, delete sections that don't apply. Compare against the filled example when unsure how much detail is enough — the goal is a doc you can defend in review, not paperwork.
