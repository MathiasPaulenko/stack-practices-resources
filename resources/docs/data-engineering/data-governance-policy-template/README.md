# Data Governance Policy Template — Companion Resources

Fillable data governance policy covering classification levels, retention schedules, RBAC, privacy procedures (GDPR/CCPA), security controls, data quality standards, and incident response — plus a quarterly access review checklist.

Full walkthrough: [Data Governance Policy Template](https://stackpractices.com/docs/data-governance-policy-template/)

## Files

- `data-governance-policy-template.md` — the complete policy document as fillable tables (7 sections)
- `access-review-checklist.md` — printable checklist for quarterly/monthly access reviews

## How to use

1. Build a data inventory first — you can't classify what you haven't mapped.
2. Fill in the classification rules table with your actual data types; tag fields L1–L4.
3. Set retention periods per category with the legal basis for each.
4. Adapt the RBAC table to your roles, then run access reviews with the checklist.
5. Keep the policy in version control; every change goes through review.
