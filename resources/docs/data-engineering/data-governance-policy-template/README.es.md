# Plantilla de Política de Gobernanza de Datos — Recursos complementarios

Política de gobernanza de datos rellenable que cubre niveles de clasificación, calendarios de retención, RBAC, procedimientos de privacidad (GDPR/CCPA), controles de seguridad, estándares de calidad y respuesta a incidentes — más una checklist de revisión trimestral de accesos.

Guía completa: [Plantilla de Política de Gobernanza de Datos](https://stackpractices.com/es/docs/data-governance-policy-template/)

## Archivos

- `data-governance-policy-template.md` — el documento de política completo en tablas rellenables (7 secciones)
- `access-review-checklist.md` — checklist imprimible para revisiones de acceso trimestrales/mensuales

## Cómo usarla

1. Construye primero un inventario de datos — no puedes clasificar lo que no has mapeado.
2. Rellena la tabla de reglas de clasificación con tus tipos de datos reales; etiqueta campos L1–L4.
3. Fija períodos de retención por categoría con la base legal de cada uno.
4. Adapta la tabla RBAC a tus roles y corre las revisiones de acceso con la checklist.
5. Mantén la política en control de versiones; cada cambio pasa por revisión.
