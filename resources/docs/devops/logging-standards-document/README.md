# Logging Standards Document Template

Fill-in companion for
[Logging Standards Document Template](https://stackpractices.com/docs/logging-standards-document/).

`logging-standards-template.md` is the same template as the site page,
stripped to `[placeholders]` so a team can adopt it directly.

## Use

1. Copy `logging-standards-template.md` into your org docs.
2. Fill the `[placeholder]` values and remove rows that don't apply.
3. Assign an owner and a review cadence in the header — and keep the changelog alive.
