# Bug Triage Template — Companion Scripts

Companion to the StackPractices template [Bug Triage Template](https://stackpractices.com/docs/bug-triage-template/).

| File | Contains |
|---|---|
| src/auto-triage.yml | GitHub Actions workflow that auto-labels incoming bugs by severity keywords |
| src/fingerprint.py | Stack-trace normalization and fingerprinting for deduplication |
| src/sla-dashboard.py | SLA aging check with Slack alert formatting |
| src/stale-bugs.sh | gh CLI query for stale S3/S4 tickets |
