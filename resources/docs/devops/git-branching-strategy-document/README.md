# Git Branching Strategy Document — Companion Resources

Downloadable Git branching strategy templates referenced by
[Git Branching Strategy Document](https://stackpractices.com/docs/git-branching-strategy-document/)
on StackPractices.

## Files

| File | What it is |
| --- | --- |
| `branching-strategy-template.md` | Blank branching strategy template: branch types, workflows, conventional commits, merge requirements, tagging, rollback and protection rules. |
| `branching-strategy-template-es.md` | The same template in Spanish. |
| `branching-strategy-example.md` | The template filled in for a fictional "Payments Service" team. |

## How to use

1. Copy `branching-strategy-template.md` into your repo (`docs/` or the wiki).
2. Fill in the version, date and owner fields in the header.
3. Adjust branch names, approval counts and merge strategies to match your team.
4. If you do not need `staging` or `release/` branches (continuous deployment), delete those rows — the document then describes GitHub Flow.
