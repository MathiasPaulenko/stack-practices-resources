# Plantilla de Manual de Ingeniería — Recursos complementarios

Plantilla de manual de ingeniería rellenable y un ejemplo realista completado para un equipo de plataforma de tamaño medio.

**Artículo**: https://stackpractices.com/es/docs/engineering-handbook-template/

## Archivos

| Archivo | Contenido |
|---------|-----------|
| `engineering-handbook-template.md` | El manual en blanco: 8 secciones (filosofía, flujo de trabajo, estándares, operaciones, crecimiento, onboarding, proceso de cambio y changelog) listo para copiar a tu wiki o repo |
| `example-filled.md` | La misma plantilla rellenada para un equipo de plataforma ficticio de 20 ingenieros — muestra el nivel de especificidad que hace útil a un handbook |
| `README.md` / `README.es.md` | Este archivo, en inglés y español |

## Cómo usarla

1. Copia `engineering-handbook-template.md` a un repo Git contra el que tu equipo pueda abrir PRs.
2. Rellena lo que ya es verdad — no escribas la versión aspiracional.
3. Abre un PR de revisión por sección con el equipo.
4. Compara tu borrador con `example-filled.md`: fíjate en cómo las entradas concretas (canales, horarios y números reales) ganan a las declaraciones vagas.
5. Pon una revisión trimestral en el calendario del responsable.

## Fuente

Parte de los recursos complementarios de StackPractices. El artículo explica el proceso de adopción, las variantes por tamaño de equipo y la cadencia de mantenimiento.
