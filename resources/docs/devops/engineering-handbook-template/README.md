# Engineering Handbook Template — Companion Resources

Fillable engineering handbook template and a realistic filled example for a mid-size platform team.

**Article**: https://stackpractices.com/docs/engineering-handbook-template/

## Files

| File | Contents |
|------|----------|
| `engineering-handbook-template.md` | The blank handbook: 8 sections (philosophy, workflow, standards, operations, growth, onboarding, change process, changelog) ready to copy into your wiki or repo |
| `example-filled.md` | The same template filled in for a fictional 20-engineer platform team — shows the level of specificity that makes a handbook useful |
| `README.md` / `README.es.md` | This file, in English and Spanish |

## How to use it

1. Copy `engineering-handbook-template.md` into a Git repo your team can open PRs against.
2. Fill in what is already true — don't write the aspirational version.
3. Open one review PR per section with the team.
4. Compare your draft with `example-filled.md`: notice how concrete entries (real channels, real times, real numbers) beat vague policy statements.
5. Put a quarterly review on the owner's calendar.
