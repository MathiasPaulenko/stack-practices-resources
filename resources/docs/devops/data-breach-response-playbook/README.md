# Data Breach Response Playbook — Companion Files

Ready-to-copy files for the [Data Breach Response Playbook](https://stackpractices.com/docs/data-breach-response-playbook/) on StackPractices.

## Files

| File | Purpose |
|------|---------|
| `data-breach-response-playbook.md` | Fillable 6-phase response playbook: detection, containment, evidence, notification, remediation, post-incident. Includes roles table and contact list. |
| `internal-breach-alert.txt` | First internal alert for Slack/email when a breach is suspected. |
| `customer-notification-email.txt` | External notification email for affected customers — legal-review before sending. |
| `status-page-update.txt` | Status page copy for investigating / identified / resolved states. |

## How to use

1. Copy `data-breach-response-playbook.md` into your wiki or incident docs and fill in the blanks: owner, contacts, jurisdiction matrix.
2. Get legal counsel to review the notification matrix and the customer email before you ever need them.
3. Keep a copy somewhere that survives a compromise of your chat and email — offline or printed.
