# Playbook de Respuesta a Violaciones de Datos — Archivos complementarios

Archivos listos para copiar del [Playbook de Respuesta a Violaciones de Datos](https://stackpractices.com/es/docs/data-breach-response-playbook/) en StackPractices.

## Archivos

| Archivo | Propósito |
|---------|-----------|
| `data-breach-response-playbook.md` | Playbook rellenable de 6 fases: detección, contención, evidencia, notificación, remediación, post-incidente. Incluye tabla de roles y lista de contactos. |
| `internal-breach-alert.txt` | Primera alerta interna para Slack/email al sospechar una violación. |
| `customer-notification-email.txt` | Email de notificación externa para clientes afectados — revísalo con legal antes de enviarlo. |
| `status-page-update.txt` | Textos para la página de estado en las fases investigando / identificado / resuelto. |

## Cómo usarlo

1. Copia `data-breach-response-playbook.md` a tu wiki o docs de incidentes y rellena los huecos: responsable, contactos, matriz de jurisdicciones.
2. Pide al asesor legal que revise la matriz de notificación y el email al cliente antes de que los necesites.
3. Guarda una copia que sobreviva a un compromiso de tu correo y chat — offline o impresa.
