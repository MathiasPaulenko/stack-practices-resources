# Plantilla de Gestión de Cambios — Companion

Versiones descargables de las plantillas de [Plantilla de Gestión de Cambios](https://stackpractices.com/es/docs/change-management-template/).

## Archivos

| Archivo | Propósito |
|---------|-----------|
| `change-request-template.md` | Solicitud de cambio en blanco — resumen, análisis de impacto, evaluación de riesgo, plan de reversión, tabla de aprobación, registro de ejecución y checklist post-cambio |
| `risk-assessment-matrix.md` | Criterios de nivel de riesgo (Bajo → Crítico) mapeados a la compuerta de aprobación requerida |
| `post-change-review-template.md` | Formulario de revisión post-cambio — varianza de ejecución, checklist de resultado, problemas, lecciones y acciones de seguimiento |
| `change-request-example.md` | Ejemplo completo: una migración de índice compuesto de riesgo Alto con aprobaciones, plan de reversión y registro de ejecución |

## Uso

Copia `change-request-template.md` en tu sistema de gestión de cambios (Jira, Linear, Notion o una carpeta `change-requests/` en el repo). Rellena las secciones 1-4 antes de pedir aprobación y completa las secciones 5-7 durante y después de la ejecución.

Clasifica cada cambio con `risk-assessment-matrix.md` para que la compuerta de aprobación coincida con el riesgo real: Bajo recibe revisión por pares, Crítico recibe al CAB.

## Requisitos

Ninguno — plantillas en Markdown plano.
