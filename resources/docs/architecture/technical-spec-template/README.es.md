# Plantilla de especificación técnica — Complemento

Archivos complementarios para la [plantilla de spec técnica](https://stackpractices.com/es/docs/technical-spec-template/) en StackPractices.

## Archivos

| Archivo | Qué es |
|---------|--------|
| `technical-spec-template.md` | La plantilla en blanco, lista para copiar a tu repo — header de estado, tablas de requisitos, plan de rollout, matriz de riesgos |
| `example-filled-spec.md` | Una spec realista completamente rellenada (Orders Service v2) que muestra cómo quedan las secciones con contenido real |

## Uso

Copia `technical-spec-template.md` en `docs/specs/` de tu proyecto, rellena los placeholders y mantenla por debajo de 10 páginas. Compara tu borrador con `example-filled-spec.md` antes de enviarla a revisión.
