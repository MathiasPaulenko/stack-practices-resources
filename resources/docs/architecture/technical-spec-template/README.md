# Technical Specification Template — Companion

Companion files for the [technical spec template](https://stackpractices.com/docs/technical-spec-template/) on StackPractices.

## Files

| File | What it is |
|------|------------|
| `technical-spec-template.md` | The blank template, ready to copy into your repo — status header, requirements tables, rollout plan, risk matrix |
| `example-filled-spec.md` | A realistic filled-out spec (Orders Service v2) showing how the sections look with real content |

## Use

Copy `technical-spec-template.md` into `docs/specs/` in your project, fill the placeholders, and keep it under 10 pages. Compare your draft against `example-filled-spec.md` before sending it to review.
