# Date Formatting — Runnable Examples

Companion code for [Date Formatting in Python, JavaScript & Java](https://stackpractices.com/recipes/date-formatting/).

- `format_date.py` — ISO 8601 output, strftime, `ZoneInfo` conversion (Python 3.9+)
- `format-date.mjs` — `toISOString()`, `Intl.DateTimeFormat` with locale + timezone
- `FormatDate.java` — `ZonedDateTime.parse`, `DateTimeFormatter`, zone conversion

Run: `python format_date.py` · `node format-date.mjs` · `javac FormatDate.java && java FormatDate`
