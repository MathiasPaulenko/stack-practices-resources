# Formateo de Fechas — Ejemplos Ejecutables

Código companion de [Formateo de Fechas en Python, JavaScript y Java](https://stackpractices.com/es/recipes/date-formatting/).

- `format_date.py` — salida ISO 8601, strftime, conversión con `ZoneInfo` (Python 3.9+)
- `format-date.mjs` — `toISOString()`, `Intl.DateTimeFormat` con locale y zona horaria
- `FormatDate.java` — `ZonedDateTime.parse`, `DateTimeFormatter`, conversión de zona

Ejecutar: `python format_date.py` · `node format-date.mjs` · `javac FormatDate.java && java FormatDate`
