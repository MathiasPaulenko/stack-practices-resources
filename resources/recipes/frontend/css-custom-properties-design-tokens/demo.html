Design Tokens Demo

Every color, space and font size on this page comes from tokens.css. Toggle the theme — only the semantic layer changes.

Semantic colors

This card reads --color-surface, --color-text and --color-border. The dark theme remaps them without touching the card.

var(--color-accent)

Fluid type

Headings use --text-fluid-* tokens with clamp(). Resize the window — no breakpoints involved.

var(--text-fluid-lg)

Spacing scale

Padding and gaps come from --space-*. --space-page also steps up at 768px and 1280px via media queries.

var(--space-6)
