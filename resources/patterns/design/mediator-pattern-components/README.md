# Mediator Pattern for UI Components — TypeScript Examples

Companion to the StackPractices pattern [Mediator Pattern for UI Components](https://stackpractices.com/patterns/mediator-pattern-components/).

| File | Contains |
|---|---|
| src/dashboard-mediator.ts | DashboardMediator routing widget events |
| src/event-bus.ts | Event-bus mediator variant with unsubscribe |
| src/chat-room.ts | Chat room mediator scenario |

Run with ts-node or compile with tsc (TypeScript 4+).
